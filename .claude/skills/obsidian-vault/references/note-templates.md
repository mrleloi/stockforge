# Note Templates — Obsidian Vault

> Reference companion to `../SKILL.md`. Verbatim frontmatter + body templates per note type.

## Entity Note

Path: `wiki/entities/<slug>.md`

```yaml
---
type: entity
subtype: company | kol | stock | market | sector
status: stub | developing | stable
tickers: [VCB, BID]  # for companies
source_mentions:
  - "[[SPEC-2026-04-001]]"
tags: [entity, vietnam, banking]
created: 2026-04-20
last_updated: 2026-04-20
---
```

## Concept Note

Path: `wiki/concepts/<slug>.md`

```yaml

  - "[[concepts/kol-calibration]]"

```

## Source Note

Path: `wiki/sources/<slug>.md`

```yaml
---
type: source
source_url: https://cafef.vn/article
source_type: article | broker_report | kol_transcript | regulatory_doc
raw_path: "../raw/research-sources/article-title.pdf"
ingested: 2026-04-20
tickers_mentioned: [VCB, TCB]
tags: [source, banking, q1-2026]
---
```

Body should extract key claims as quotes (numbers verbatim from source — I-S2; do NOT recompute).

## Thesis Note

Path: `wiki/thesis/<YYYY-MM-DD-ticker>.md`

Live tracking lives in `agent-workspace/memory/thesis-log/`. The wiki note is a stable summary linked from the thesis-log entry.

## Synthesis Note

Path: `wiki/synthesis/<slug>.md`

Cross-source analysis. Body must cite sources via `[[sources/<slug>]]` for every claim. No LLM-computed numbers — quotes only.

## Spec Note

Path: `wiki/specs/tier<N>-<type>/<spec-id>-<slug>.md`

Generated by `spec-to-wiki` skill from `specs/tier<N>-<type>/<spec>.md`. Wiki version adds wikilinks to entities + concepts + glossary terms. Source spec stays canonical; wiki note is navigable view.

## Log Template — `wiki/_log.md`

Append a single line per ingest:

```markdown
- 2026-04-20 — `[[sources/2026-04-vcb-q1-earnings-cafef]]` — VCB Q1 2026 earnings article (CafeF)
- 2026-04-21 — `[[entities/vcb]]` — Stub created from source mention
```

## Search Patterns

### By Ticker (bash)

```bash
grep -rn "VCB\|Vietcombank" wiki/ --include="*.md"
```

### By Frontmatter (Obsidian Bases query)

```
TABLE status, created, tickers_mentioned
FROM "wiki"
WHERE type = "source" AND tickers_mentioned
```

### By Backlink

Open any note in Obsidian → "Linked mentions" panel surfaces backlinks across the vault.
