## Anti-Patterns in Proposal Authoring

- **Synthesized rule that drops the incident**: every cluster's prevention rule should reference at least one source incident verbatim.
- **Q-E3 priority defended only by name**: must explicitly say why-not-the-other-two.
- **Clusters of exactly 3 with sim near floor**: mark confidence LOW; don't claim HIGH.
- **Capability-map touch missing**: every cluster touches at least one cell. If novel task_class, propose adding to vocabulary.
- **HIGH confidence on judgment-only patterns**: reserved for deterministic-checkable rules.

## Tips

- Order clusters in Summary by Q-E3 priority (HOOK → SKILL → CHARTER), then by size desc within tier.
- Keep synthesized rules to 1-3 sentences. Longer = lost compression value.
- For rephrasing: preserve "Why" (incident + rationale) lines from source rules — not just the "Rule" line.
- Always cite Q-E3 verbatim source: `queued-grill-master.md § Q-E3` (closed via S8 promotion path implementation).
