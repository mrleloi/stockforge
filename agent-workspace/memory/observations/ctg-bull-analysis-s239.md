## Key Lessons (L-S239-X candidates)

1. **Data-scarcity honesty pays**: BVH failed because it lacked fundamental anchor for technical points. CTG passes by grounding technical points within a multi-category framework anchored to explicit earnings data. Lesson: ALWAYS pair technical valuation signals with fundamental/macro/narrative anchors; if missing, cap conviction WEAK and disclose gap.

2. **RSI neutral vs. oversold distinction matters**: BVH's RSI 7.24 was mechanical oversold → WEAK conviction. CTG's RSI 42.47 is neutral → MODERATE conviction justifiable when paired with price pullback context. Lesson: Don't assume RSI-extreme = bullish signal; assess regime (panic vs. orderly pullback) before conviction claim.

3. **Sector momentum as macro-level evidence**: MBB +15% YoY profit (vs. CTG +63%) provides bounds-check on growth sustainability and differentiates structural cycle from idiosyncratic outperformance. Lesson: Always cite peer comparatives when making absolute growth claims; lack of peer data is a HIGH-priority gap.
