## Smoking-gun evidence: `promotion-cycle-trigger.sh` fires 20× today, escalates 0×

**Hook**: `scripts/hooks/promotion-cycle-trigger.sh` (HH-C.4 + Rule 4a draft per L-S35-1; wired in Stop chain).

**Empirical evidence** (verbatim from `.promotion-cycle.log`, last 5 entries today):
```
[2026-05-05T18:48:20+07:00] promotion-cycle-trigger: latest_session=0 last_promote=S43 delta=-43 latest_phase=3 last_phase=0 phase_changed=1
[2026-05-05T19:03:58+07:00] promotion-cycle-trigger: latest_session=0 last_promote=S43 delta=-43 latest_phase=3 last_phase=0 phase_changed=1
[2026-05-05T19:12:38+07:00] promotion-cycle-trigger: latest_session=0 last_promote=S43 delta=-43 latest_phase=3 last_phase=0 phase_changed=1
```

20 entries today (S49b through S50). Every single entry: `latest_session=0`. Reality: latest session is S50.

**Root cause** (script line 23):
```bash
SESSION_LINE=$(grep -E '^\*\*Session N\*\*:' "$EXEC_FILE" | head -1 || true)
```

The grep pattern is `^\*\*Session N\*\*:` — looks for the literal string `**Session N**:` (with literal "N"). The current `current-execution.md` uses headers like `## S50 — Phase 3.5 master-plan authored` instead. Pattern mismatch → `SESSION_LINE` is empty → `LATEST_SESSION=0`.

**Cascade**:
- `SESSION_DELTA = LATEST_SESSION - LAST_PROMOTE_SESSION = 0 - 43 = -43`
- Hard-block rule: `[ "$SESSION_DELTA" -ge 8 ] || { [ "$PHASE_CHANGED" -eq 1 ] && [ "$SESSION_DELTA" -ge 1 ]; }`
- Both legs FAIL because `-43 < 8` AND `-43 < 1`
- Soft-warn rule: `[ "$SESSION_DELTA" -ge 5 ]` — also FAILS (-43 < 5)
- Hook exits 0 silently with no escalation, every time

**Reality check** — actual lessons accumulated since S43c last promote-rule:
- L-S43f-2, L-S44-1 (and family M-S45-2, M-S47-1), L-S45-1, L-S45-2, L-S48-1, L-S48d-1, L-S48m-1, L-S49a-1, L-S49-1, L-S49-2, L-S49b-1, L-S49b-2, L-S49b-3, L-S49b-4 — at least 14 lessons (~6+ sessions of accumulated work).

**Per the hook's stated rule**, the hard-block "≥8 sessions OR phase boundary crossed without promote-rule" condition has been true since at least S48 (PHASE_CHANGED=1 between S43 phase=2 and current phase=3 detected correctly), but the broken arithmetic made it impossible to fire.

**Severity**: HIGH. The promote-rule cycle is the harness's mechanism for converting accumulated agent-notes lessons into deterministic hooks (hook FIRST, skill SECOND, charter LAST per Q-E3 closed answer). With this gap, every lesson stays as advisory note instead of becoming a binding hook — exactly the failure mode that surfaced ~20 unresolved Auto-detect candidates.

## Meta-pattern statement (T1.3 deliverable)

**The Phase 2.5 audit measured the wrong layer.** It validated:
1. Script file exists at expected path.
2. Script syntax is valid (`bash -n` clean).
3. Script wired in `.claude/settings.json` correct chain.
4. Manual smoke invocation exits 0 with synthetic input.

It did NOT validate:
1. Hook fires on real session events (vs synthetic smoke input).
2. Hook's detection logic produces truthful output on real session telemetry shape.
3. Hook escalates when threshold crossed (vs silently no-op).
4. Hook's escalation channel reaches a human or LLM with action authority.

The 4 unmeasured layers are where production failures live. Specifically:
- A hook can be wired + syntax-clean + smoke-passing + still useless if its grep pattern doesn't match the real file format (HH-C.4 promotion-cycle).
- A hook can be wired and "look right" but never fire if its trigger event doesn't actually occur in normal operation (HH-D Mode-E detector — no detection trigger ever fires).
- A hook can fire correctly but write to a log channel no aggregator reads (HH-B.3 failure_mode classification).

**Counter-rule** (target for Phase 3.5 T8 charter ratification):

> **"Harness must self-verify firing on real telemetry, not self-attest existence on synthetic input."**
>
> Concretely:
> 1. Every hook ships with a companion firing-test that synthesizes a known-truthy and known-falsy input matching real session-data shape.
> 2. Every hook's escalation path is verified end-to-end (hook fires → log entry exists → aggregator picks up → surfaces to LLM via system-reminder OR to human via notification).
> 3. Phase-close audit MUST include "empirical firing evidence" column per hook, not just "wiring + syntax-clean".
> 4. Tracks claiming DONE are NOT closed until empirical-firing evidence is captured for ≥80% of declared hooks.
