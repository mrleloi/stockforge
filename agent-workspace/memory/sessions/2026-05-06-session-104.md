1. **File shrinkage made projection moot**: `current-execution.md` was 304 KB at S99 → now **19336B / 19 KB** at S104 (well under 24 KB cap; `tracking-retention.sh` enforces). Grep on 19 KB markdown is <50ms; TSV projection saves ~10ms. Maintenance burden + drift risk dominate the gain.

These hooks don't benefit from a TSV projection — they need precise field access on small bounded scope, which the markdown anchored-awk pattern already provides.
