- **L-S46-1 (LOW)**: When ruff auto-fix removes `Any` imports but `Any` is used in field annotations, the linter introduces `F821 Undefined name Any`. Always check that ruff's import cleanup doesn't break field-level type annotations in dataclasses that mix `Callable` and `Any`. Fix: add `from typing import Any` explicitly alongside `Callable` for adapters that need both.
