**T2 — Implement auto-migrate logic** (~2K main): Inserted AUTO-MIGRATE block in `scripts/hooks/tracking-retention.sh` between Cap-1 metric reads and cap-check WARN logic. Algorithm:
1. Pre-condition: `CE_LOC > 200 && CE_SESSIONS >= 2 && archive_file_exists`.
2. Find newest dated archive via `ls -t current-execution-archive-*.md | head -1` (falls back to bare archive if dated form absent).
3. Locate oldest inline session block: `grep -n "^## S[0-9]" | tail -1` returns line number of last `## S<N>` header.
4. Extract block: `tail -n +"$LAST_HEADER_LINE"` → tmpfile.
5. Append block to archive with provenance footer: `**Migrated to archive at S<CURRENT> (auto-migrate via tracking-retention.sh; LOC-cap-driven; S135 promotion).**`.
6. Trim current-exec: `head -n "$TRIM_LINE"` → replace.
7. Update archive frontmatter: `sed -i.bak -E "s/^sessions_archived: S[0-9]+ /sessions_archived: S<NEW> /"`.
8. Re-read CE_LOC + CE_SESSIONS post-migration so downstream WARN logic sees updated state.
9. Log AUTO-MIGRATED event line for observability.
