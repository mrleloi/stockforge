## Lessons learned (potential agent-notes promotions for S9+)

### L-S8-1: Skill smoke-test as observation artifact (dual-purpose)
**Context**: decompose-work skill smoke-test inline produced both (a) skill validation evidence AND (b) actual design decomposition for promote-rule (the very next deliverable). Single artifact served both.
**Rule**: When a new skill is shipped + a downstream consumer is also being authored same session, run skill on the consumer task as smoke-test. The decomposition artifact informs implementation; the implementation success retroactively validates the skill.
**Severity**: low (technique optimization)

### L-S8-2: Default thresholds need real-corpus calibration
**Context**: promote-rule default Jaccard threshold = 0.7 was D-003 spec. Real corpus (18 agent-notes) produces 0 clusters at 0.7 (too strict). Threshold tuning is part of skill's intended loop.
**Rule**: When shipping a parameterized skill with a default threshold, smoke-test on real corpus + record in skill body the default's behavior (and recommended tune-down protocol if no signal). Don't ship optimistic defaults that hide signal.
**Severity**: low (skill UX)
