## Technical Issues Encountered and Resolved

1. **stdin conflict with Python heredoc** — `STDIN_PAYLOAD` consumed stdin before heredoc Python. Fixed: write Python to temp file with `mktemp` before consuming stdin.
2. **Allow-list false positive on `test_target/` directory** — bash `case */test_*.py)` matches path components. Fixed: `basename` of `rel_path` for filename-only matching.
3. **`wc -l` whitespace causing integer comparison failure** — `wc -l` returns leading spaces. Fixed: pipe all integer outputs through `tr -d '[:space:]'`.
4. **`printf '---\n...'` bash option parsing error** — printf treats `---` as option flag. Fixed: `printf '%s\n' '---' ...` form throughout.
5. **TC8 frontmatter exemption not working** — same printf bug in TC8 setup. Fixed.
6. **TC9 excluded zone firing via Stop mode** — Stop mode scans all prior test fixtures. Fixed: fresh sandbox for TC9 with only empty audited directories.
