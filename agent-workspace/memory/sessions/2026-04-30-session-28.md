## Decisions

### IMPL-S28-1 — vnstock 4.0.2 dropped TCBS source; TcbsAdapter calls TCBS public REST directly

**Tier**: IMPL.

**Issue**: master-plan § S28 deliverable #3 specifies `tcbs_adapter.py` using "TCBS public API" with `source_provider=TCBS`. Probe at S28 entry confirmed vnstock 4.0.2 supports only `kbs / vci / msn / dnse / binance / fmp / fmarket` for `Quote(...)`; **TCBS removed** in the 4.0 migration. Two-source reconciliation pattern is the master-plan's binding intent.

**Resolution**: VnstockAdapter uses VCI source via `vnstock.api.quote.Quote(symbol, source='VCI')`. TcbsAdapter calls TCBS's documented public REST endpoint (`https://apipubaws.tcbs.com.vn/stock-insight/v2/stock/bars-long-term`) directly via httpx. Both adapters satisfy `BarProviderPort`. The naming + intent of "two distinct providers for reconciliation" is preserved.

**Why not switch second adapter to KBS or DNSE**: would silently rename without surfacing the TCBS deprecation; future readers would not know why "tcbs_adapter.py" wasn't TCBS. Direct REST call to TCBS keeps the intent explicit; if the endpoint pattern moves, the failure mode is visible (404) and the adapter raises rather than silently mapping to a fake source.

**Source evidence**: `Quote(symbol='VHM', source='TCBS')` raises `ValueError: ... source là kbs, vci, msn, dnse, binance, fmp, fmarket` (probed at S28 entry); TCBS public-API public docs (historical) for endpoint pattern; agent-notes "stale data must propagate".
